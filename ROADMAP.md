# BitNeet Roadmap

## Phase 1 — Foundation

- [x] Basic TCP client-server chat
- [x] Terminal-based interface
- [x] BNP1 (BitNeet Protocol v1)
- [x] JSON message packets
- [x] Newline-delimited JSON communication
- [x] LAN communication
- [x] LAN cross-device communication
- [x] Git/GitHub project setup

## Phase 2 — Core Chat

- [ ] Join notifications
- [ ] Leave notifications
- [ ] Proper formatted message display
- [ ] Graceful client disconnect
- [ ] Basic chat commands
- [ ] Better error handling
- [ ] Robust TCP message framing
- [ ] Persistent BitNeet user IDs
- [ ] User-to-user addressing

## Phase 3 — Security

- [ ] User authentication
- [ ] Encrypted communication
- [ ] Secure key exchange
- [ ] Message integrity

## Phase 4 — Beyond LAN

- [ ] Internet communication
- [ ] Server discovery / connection system
- [ ] NAT and firewall considerations
- [ ] Reliable long-distance communication
- [ ] Identity / connection discovery
- [ ] Persistent identity across networks and devices

## Phase 5 — Advanced Features

- [ ] Message history
- [ ] File transfer
- [ ] Multiple rooms / channels
- [ ] Offline message handling
- [ ] Optional end-to-end encryption

## Long-Term Direction

BitNeet is intended to remain lightweight and terminal-first rather than becoming a full GUI or WhatsApp-style application.

The focus is on simple communication, a clear protocol, portability, and progressively improving reliability and security.
